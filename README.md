# ليبيا هب | Libya Hub

دليل ليبيا الشامل: تطبيقات، مصارف، جهات حكومية، متاجر، وظائف، سفر، تعليم،
طاقة، صحة، وأخبار، مع بيانات مباشرة (عملات، ذهب، نفط، طقس، أخبار).

## ما الذي يعمل مباشرة (بيانات حية)

| البيان | المصدر | ملاحظات |
|---|---|---|
| سعر الصرف الرسمي | مصرف ليبيا المركزي `cbl.gov.ly/currency-exchange-rates` | يُقرأ من جدول الصفحة الرسمية |
| السوق الموازي | عين ليبيا `eanlibya.com/exchangerate` | للدلالة فقط |
| الذهب | `api.gold-api.com` (بدون مفتاح) | السعر العالمي × سعر الدولار، لا يشمل المصنعية |
| الطقس لكل المدن | Open-Meteo (بدون مفتاح) | |
| الأخبار | تغذيات RSS من عين ليبيا، ليبيا هيرالد، الوسط، ليبيا أوبزرفر، المركزي | المصدر الذي لا يستجيب يظهر بجانب زر لفتح موقعه |
| النفط (برنت) | oilpriceapi.com | **يحتاج مفتاحاً مجانياً**، انظر أدناه |

كل شيء يُحدَّث تلقائياً كل 5 دقائق، ويُحفظ آخر إصدار للعمل بدون إنترنت.

## البناء

```bash
flutter pub get
flutter build apk --release \
  --dart-define=OIL_API_KEY=مفتاحك_من_oilpriceapi.com \
  --dart-define=CONTACT_EMAIL=بريدك@مثال.com
```

الوسيطان اختياريان. في GitHub Actions أضف أسراراً باسم `OIL_API_KEY` و`CONTACT_EMAIL`
(يمكن تركها فارغة).

## الفنادق

شاشة «الفنادق حسب المدينة» مرتبة بالمناطق ثم المدن. لكل مدينة زر بحث في خرائط جوجل
وBooking. الفنادق المسجلة في `lib/data/hotels.dart`: أرقام الهاتف والصفحات لا تُضاف
إلا إذا كانت من الموقع الرسمي للفندق، وباقي الفنادق يفتح زر الخريطة باسمها.

## الأيقونة واسم التطبيق

- الأيقونة: `assets/images/libya_icon.jpg` ولُّدت منها ملفات `mipmap-*` كاملة
  (طبقة أمامية معتمة + أيقونة قديمة ودائرية) فلا يظهر مربع أبيض.
  لا تشغّل `flutter_launcher_icons` (أُزيل إعداده) حتى لا يكتب فوقها.
- الاسم: `res/values/strings.xml` (Libya Hub) و`res/values-ar/strings.xml` (دليل ليبيا).

## الروابط

كل الروابط في `lib/data/directory.dart` جُمعت من مواقع رسمية أو من صفحات المتجر
نفسها. التطبيقات التي لم يُتحقق من معرّف حزمتها تفتح **بحثاً في جوجل بلاي**
بدل رابط قد لا يعمل.

للتحقق الدوري:

```bash
python3 tools/check_links.py
```

ويعمل تلقائياً كل أسبوع عبر `.github/workflows/check_links.yml`.

## إضافة عنصر جديد

في `lib/data/directory.dart` أضف داخل المجموعة المناسبة:

```dart
DirItem.web('اسم الموقع', 'وصف قصير', 'https://example.ly/'),
DirItem.app('اسم التطبيق', 'وصف', package: 'com.example.app'),
```

## هيكل المشروع

```
lib/
  config.dart            إعدادات وقت البناء
  data/                  المدن والدليل (كل الروابط هنا)
  services/              البيانات المباشرة والتحليل وحالة التطبيق
  widgets/               الشريط المتحرك، اختيار المدينة، بطاقات الدليل
  views/                 الشاشات
assets/translations/     ar.json و en.json
tools/check_links.py     فاحص الروابط
```

## التحديث التلقائي والمحتوى الجديد دون تحديث من المتجر

1. **محتوى بعيد:** التطبيق يقرأ `content/content.json` من GitHub كل 30 دقيقة (ويحفظ آخر نسخة).
   عدّل الملف وادفعه فيصل المستخدمين: تطبيقات وروابط جديدة، أقسام جديدة كاملة، فنادق،
   مصادر أخبار، إعلان أعلى الشاشة، رسالة «تحديث متوفر»، وإعدادات الإعلانات.
   الأمثلة الكاملة في `content/example_full.json`. المستودع يجب أن يكون **عاماً (public)**.
   أي خطأ في JSON أو رابط غير آمن يُتجاهل ويبقى المحتوى السابق.
2. **تحديث جوجل بلاي الداخلي:** عند توفر إصدار جديد في المتجر ينزّله التطبيق بالخلفية ويعرض زر «إعادة التشغيل».
3. **نافذة تحديث:** ارفع `update.versionCode` في content.json فتظهر نافذة «تحديث الآن» لمن يملك إصداراً أقدم.

## إعلانات Unity (غير مزعجة)

بدون Game ID لا تظهر أي إعلانات. لتفعيلها ضع في `content/content.json`:

```json
"ads": { "gameId": "رقم_اللعبة", "testMode": true }
```

وجرّب أولاً (testMode = true)، ثم غيّرها إلى `false` عند النشر. أسماء الأماكن الافتراضية
`Banner_Android` و`Interstitial_Android` و`Rewarded_Android`، وغيّرها بنفس الكتلة إن اختلفت في لوحة Unity.

القواعد المضمّنة: بانر صغير أسفل شاشات القوائم فقط. إعلان بيني واحد كل 5 شاشات كحد أدنى
وبفاصل 4 دقائق وبحد 6 يومياً، وبعد دقيقتين من فتح التطبيق. لا إعلانات في الطوارئ والصلاة والنماذج.
زر «إخفاء الإعلانات مؤقتاً» في القائمة (مشاهدة إعلان مكافأة = 24 ساعة بلا إعلانات).
الحدود لا تتجاوز مدى آمناً حتى لو كُتبت قيمة خاطئة في الملف.
